# AI Text Analyzer

A Python-based AI application that analyzes text using a locally running Large Language Model (LLM).

The application uses **Ollama and Llama 3.2 (1B)** to identify sentiment, extract keywords, and generate a short summary.

## Features

- Sentiment classification: Positive, Negative, or Neutral
- Keyword extraction
- Text summarization
- Structured JSON responses
- AI response validation
- Error handling and empty-input checks
- Interactive command-line interface
- Automated unit tests

## Technologies Used

- Python
- Ollama
- Llama 3.2 (1B)
- JSON
- unittest

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/salwa-kt/AI-Text-Analyzer.git
cd AI-Text-Analyzer
```



**2. Install Ollama**

Download Ollama from https://ollama.com.

**3. Download the language model**

```bash
ollama pull llama3.2:1b
```

**4. Install Python dependencies**

```bash
python -m pip install -r requirements.txt
```

## Usage

Make sure Ollama is running, then execute:

```bash
python ai_text_analyzer.py
```

Enter text when prompted. Type `quit` to exit.

## Example Output

**Input:**

I love learning Python and building AI applications!

**Output:**

```text
Sentiment: positive
Keywords: Python, AI, applications
Summary: The user enjoys learning Python and building AI applications.
```

Results may vary because they are generated by an AI model.

## Testing

Run the automated unit tests:

```bash
python test_ai_text_analyzer_unittest.py -v
```

The tests cover:

- Valid AI responses
- Missing required fields
- Invalid sentiment labels
- Incorrect keyword data types

## How It Works

1. The user enters text.
2. Python sends the text to Llama 3.2 through Ollama.
3. The model generates a JSON response containing sentiment, keywords, and a summary.
4. The application validates the response's structure and data types.
5. The validated results are displayed to the user.

## Limitations

- Requires Ollama and a downloaded local model.
- AI-generated classifications and summaries may be inaccurate.
- Output validation checks the response format, not the accuracy of the analysis.
- The application currently uses a command-line interface.
